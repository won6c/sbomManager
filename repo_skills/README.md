# Repository Skills Used for SBOM Manager

This directory stores the reusable skills/workflows used while building and documenting this repository.

| Skill | Purpose |
|---|---|
| `sbom-manager-analysis` | Core SBOM Manager development workflow: probes -> intelligence -> reachability -> TARA risk. |
| `todo-tracking-reconciliation` | How remaining work is reconciled into `progress.json`, `TODO_TRACKING.md`, and `SESSION_LOG.md`. |
| `final-presentation-builder` | Final-report slide workflow aligned with the required grading contents. |

These are repo-local documentation skills, not runtime code. They are intended to preserve project-building knowledge for future maintainers.
