# Final Presentation Builder

## Overview
Build a concise <8 minute final presentation with exactly 10 slides: cover, 8 report slides, and closing slide.

## Required Contents Mapping
- Problem and motivation with user story -> early slide.
- Project overview and goals -> architecture/goal slide.
- Harness engineering repository structure -> dedicated repository/documentation slide.
- Test and evaluation -> validation slide.
- Demo screens -> UI/demo slide.
- Contributions of each member -> contribution slide.
- Challenges and lessons learned -> final report slide.
- Closing slide must include GitHub repository URL.

## Recommended 8 Report Slides
1. User story and motivation.
2. Project overview and goals.
3. Harness engineering structure and documentation.
4. System architecture and data flow.
5. Core implementation highlights.
6. Test and evaluation.
7. Demo screens and user workflow.
8. Contributions, challenges, and lessons learned.

## Verification Checklist
- [ ] 1 cover slide.
- [ ] 8 report slides.
- [ ] 1 closing slide with GitHub repository URL.
- [ ] Exported PDF exists.
- [ ] Slide text is readable and no placeholder remains.
